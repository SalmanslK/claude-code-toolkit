# new-feature

**B1 · Features.** **Trigger:** start a feature: from an FSD section to an approved plan.
**Packs:** none.

## Steps

1. `/book:check-sources` — is the section current?.
2. `/book:plan` — the template, the FSD sections, the feature-index row, the Tasks.
3. `/book:outline-api` — the plan's API section, from the wireframes and the FSD.
4. `/book:impact` — what it reaches.
5. `/book:raise question` — for each gap.
6. ✋ The person approves the plan; the session ends.

## Loops

- ⟲ steps 2–5 while questions come back answered.

## Done when

The plan is approved with no unraised gap; next, `build-task` for each task.
